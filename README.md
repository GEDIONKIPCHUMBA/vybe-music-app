# VYBE – Your sound. Your world.

A modern music streaming UI inspired by contemporary dark-theme players. Features a full desktop home experience and a mobile full-screen player.

## Features

- **Desktop Home**
  - Sidebar navigation (Home, Search, Library, Likes, Playlists)
  - Personalized greeting
  - New release hero banner
  - Quick picks, Made For You mixes, Browse by Genre
  - Sticky now-playing bar with progress & controls

- **Mobile Player**
  - Full-screen immersive view
  - Large album art
  - Transport controls, like, lyrics & queue shortcuts
  - Smooth progress scrubbing

- **Interactions**
  - Play / pause, next / previous
  - Progress bar seeking
  - Track switching from Quick Picks
  - Keyboard shortcuts: `Space` (play/pause), `←` / `→` (prev/next)
  - Responsive layout (sidebar hides on smaller screens)

## Tech Stack

- Pure **HTML / CSS / JavaScript** — no frameworks
- Inter font from Google Fonts
- CSS Grid + Flexbox
- Gradient-heavy dark purple / pink aesthetic

## Live Demo

Open `index.html` in any modern browser, or serve with a local static server:

```bash
npx serve .
# or
python -m http.server 8000
```
